## 恢复期间删除阻塞

现场只读确认 pending 节点为在线的 rnlos（21），恢复失败原因是规则 397 的 26566 实际占用，并非等待上线。全局 pending 检查原先阻止所有规则操作，用户无法删除冲突规则。

允许 pending 期间单条删除：复用 forceDeleteForward 的用户归属检查，在事务内删除数据库规则并将相关节点恢复快照替换为当前有效配置，然后尝试同步。失败继续保留更新后的快照，已删除规则不会被恢复；其他配置变更仍被保护。提示改为可能存在端口冲突或离线，不再一律要求等待上线。未直接清空生产恢复队列。
