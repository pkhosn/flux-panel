# 登录注册验证流程

用户已确认：先校验填写内容，再弹验证码；通过后自动提交。保留网站验证码开关。

- [x] 阅读登录/注册页面与服务端验证码二次校验实现。
- [x] 弹层挂载后初始化，取消固定延时；初始化失败可重新尝试。
- [x] 保存本次提交快照，显式传递凭证；拦截重复提交和失效回调。
- [x] 本地构建及浏览器验证登录/注册、取消、失败重试、关闭验证码与重复点击。
- [x] 发布不可变前端包、验证匿名下载及生产镜像，再推送 beta。

复验：开启验证码时，填写完整资料并点击提交，验证前不得出现登录/注册请求；成功后只发送一次携带当次凭证的请求。取消后不提交，重新点击出现新验证；账号错误后须重新验证。关闭验证码时提交不弹层。模拟 SDK 不可用应提示错误且恢复按钮。

追加用户需求：修复刷新时先显示 flux-panel。HTML 在加载应用前恢复缓存中的网站名；首次无缓存时等待配置，不显示项目占位标题。浏览器延迟应用脚本与配置接口，检查首屏及刷新标题。

本地验证通过：Node20 npm run build；Playwright /tmp/flux-browser-check/auth-captcha.cjs（用SDK回调及接口模拟验证流程）和 title-no-flash.cjs（延迟脚本/接口验证标题）。两项均在静态构建与生产镜像端口27366重复通过，可设置 BASE_URL 复验。匿名下载内容与发布包逐字节及SHA256一致。未修改生产验证码配置，未连接生产账号。
