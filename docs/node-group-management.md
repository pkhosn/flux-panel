# 节点分组管理

用户已确认实施：独立管理分组（新增/删除）、默认全部节点、多选加入/移出、卡片直接切换，保留历史分组和节点管理权限。

- [x] 新增分组表并迁移历史名称，沿用 node.group_name，避免改动现有隧道接口。
- [x] 分组 API 支持列表、新增、删除、批量设置；管理员可管理全部节点，普通用户仅自己的节点。
- [x] 页面管理弹窗、多选、卡片下拉和表单选择，无单独未分组筛选。
- [x] 本地 Maven、前端构建与浏览器验证，发布静态包后推送 beta。

每节点一个分组。删除只清除有权管理节点的归属，不删除节点、不重启服务。普通用户组隔离；管理员使用公共分组。已有名称自动登记到所属管理域，空分组由独立表保留。未归组节点仅显示在全部节点中。

本地验证：既有 Maven clean test 全部通过，NodeGroupManagementTest 验证历史名称登记、空组新增、重复拒绝、批量权限、移出、删除保留节点、管理员跨所有者分组；npm build 与 git diff --check 通过。临时浏览器 node-group-mgmt.cjs 验证空分组管理、批量加入/移出、只读节点不可选、卡片切换、删除保留节点和 390px 无溢出。分组列表对普通用户仅提供自身管理域的分组；只读节点可显示其原分组但不可修改。
