# 批量文本编辑规则

用户确认格式为 `目标地址|名称|入口端口`，选中后自动填入原值，按打开时的固定 ID 顺序逐行对应，不能增删或重排条目。其他配置保留。

- [x] 后端预校验所有行和权限，再逐条更新并报告失败；复用原更新服务。
- [x] 前端固定所选快照，文本弹窗、行数与格式错误提示、结果列表，提交期间防重复。
- [x] 本地 Maven、前端构建、浏览器验证，发布前端资源并推送。

共享 TLS 规则无法独立改变入口端口，拒绝端口改变；不同入口原端口不一致的规则不自动压成一个端口。失败规则保留选中，已成功规则不回退。批量按原顺序执行，端口交换可能冲突，不临时释放其他规则端口。

验证：ForwardBatchEditTest 通过，覆盖行数/格式预校验、混合归属权限拒绝、部分失败及高级字段不覆盖。npm build、git diff --check 通过；临时 batch-rule-edit.cjs 检查预填、固定 IDs、行数错误不提交、修改内容、失败保留选择及窄屏。
